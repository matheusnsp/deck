From download to the first button.

Deck turns any phone into a button panel for your computer. It works on Mac, Windows and Linux; the panel opens on iPhone, Android, a tablet or another computer. This guide takes you from zero to using it.

1Download

  1. On Mac and Linux, the easiest way is the Terminal line on the Deck website: it creates a Deck folder in your home folder, already cleared by the system, and starts the deck. Running the same line again updates Deck without losing your buttons.
  2. Or download the deck.zip file and unzip it into a folder of yours — for example Documents/Deck. That's it: nothing is installed in the system, and to uninstall just delete the folder.
  3. Check that the folder has server.py, the web folder and the start files (Iniciar no Mac.command, Iniciar no Windows.bat, iniciar-linux.sh — "Iniciar" means Start).
ComputerNeeds
MacNothing. If the Mac asks to install the "command line developer tools" the first time, accept (it's the Python that ships with it).
WindowsPython 3 — download it from python.org and, in the installer, check Add python.exe to PATH.
LinuxPython 3 (already included in practically every distribution).

2Start on the computer

ComputerHow to start
MacDouble-click Iniciar no Mac.command. If you installed with the Terminal line from the site, it opens right away. If you downloaded the zip, macOS blocks it the first time ("Apple could not verify…"): click Done, go to System Settings › Privacy & Security, scroll to the bottom and click Open Anyway — once only. On macOS 14 or earlier, right-click › Open. With no warning at all: Terminal in the folder and python3 server.py.
WindowsDouble-click Iniciar no Windows.bat. If Windows asks whether you really want to run it, untick Always ask before opening this file and click Run (or More info › Run anyway) — that way it won't ask again. If the Firewall asks, Allow access (private networks).
LinuxIn the folder, run ./iniciar-linux.sh (or python3 server.py).

A terminal window opens with the deck's address and then the editor opens in the browser (http://localhost:8787/editar). Keep the terminal window open while you use it: it's the one running the deck. To turn it off, close the window or press Ctrl+C in it.

Permissions (first time only)

  • Mac: for buttons that press keys, macOS asks for Accessibility (System Settings › Privacy & Security › Accessibility › turn on Terminal) — the same permission lets the deck see incoming calls. To see the browser's open tabs and to control Spotify and Music in the DJ, it asks for Automation: click Allow. If the Mac's Firewall is on, click Allow when it asks about Python.
  • Windows: only the Firewall prompt above.
  • Linux: on Wayland, keys and text use wtype or ydotool; on X11, xdotool. The deck tells you in the terminal if one is missing.

Want the editor as an app with its own window? In Safari: File › Add to Dock. In Chrome or Edge: menu ⋮ › Cast, save and share › Install page as app.

3Connect the phone

In the editor, click Connect phone. A QR code appears: open the phone's camera, point it and tap the link. Then save it to the home screen to open it as an app — iPhone: Share › Add to Home Screen; Android: menu ⋮ › Add to Home screen.

The deck only needs a network path between the phone and the computer. There are four, and the Connect phone window has a tab for each:

Wi-Fi

Both on the same network. The usual way — just scan. On a Mac the link comes by name (YourMac.local), which doesn't change when the router changes the IP; Android doesn't open by name, so there use By IP.

USB cable

At the desk, no router needed: zero lag and it charges the phone. iPhone: Settings › Personal Hotspot › Allow Others to Join, then plug in the cable. Android: USB tethering (on a Mac, only Android 14 or newer).

Bluetooth

No cable and no router. Personal Hotspot (or Bluetooth tethering) on, pair the two and, on the Mac, Bluetooth menu › phone › Connect to Network. Slower, but more than enough for pressing buttons.

Computer's network

When there's no Wi-Fi at all, or the phone plan has no hotspot. Mac: Internet Sharing over Bluetooth PAN. Windows: Mobile hotspot. Linux: Wi-Fi hotspot.

On each tab the deck detects by itself when the phone shows up through that path and shows the right QR code. USB cable and Bluetooth use the phone's Personal Hotspot, which has to be enabled on your carrier plan (almost all are).

With the cable connected, the computer may start using the phone's internet. On a Mac: System Settings › Network › ⋯ › Set Service Order and keep Wi-Fi above "iPhone USB".

4Build the buttons

Everything is done in the editor, on the computer; the phone mirrors it instantly. Each page in the sidebar is a screen on the phone (4×2 by default). Click an empty space to create a button, or use ＋ Apps and ＋ Sites at the top.

  • AppPick from the list of installed programs (on a Mac, the ones in the Applications folder and in your other folders, such as Downloads) — the button gets the app's own icon. Search matches initials too: “vs code” finds Visual Studio Code.
  • SiteType an address or pick from open tabs, bookmarks and most visited. It gets the site's official icon.
  • Keyboard shortcutRecord a combination, like ⌘C or Ctrl+Z, to press it remotely.
  • TextTypes a ready-made phrase wherever the cursor is.
  • Media and VolumePlay/pause, skip, up, down, mute.
  • MicrophoneMutes and unmutes; the light stays on on the phone while muted.
  • PowerShut down, restart, sleep or lock the computer. Asks for a second tap for safety.
  • Go to pageJumps to another page on the phone.
  • ModeFocus, work, study: turns on Do Not Disturb, opens and closes apps, sets the volume and shows a timer (section 6).
  • CallAnswer, decline, mute, camera and hang up in Zoom, Teams, Meet and others (section 6).

Drag the buttons to rearrange and the pages in the sidebar to change their order (or ⌥+↑/↓). The eye next to a page's name hides it from the phone without deleting it — click again to bring it back. Click the card's ··· to edit (name, icon, color, confirmation), and use Settings (gear) for the theme, the grid size, the language and the QR code. ⌘Z undoes. Everything is saved automatically to the folder's config.json file — which you can copy to another computer.

Turn the computer on from the phone? A computer that's off can't be turned on — nothing is running on it to receive the request. The way out is Sleep instead of shutting down: it wakes with any key or the mouse and, on a Mac with "Wake for network access" on and an Apple TV, HomePod or Apple router on the network, it wakes by itself when Deck opens on the phone.

5Use it on the phone

  • Open it from the home screen icon, in landscape: that's how the 4×2 grid fits.
  • Swipe sideways to change pages.
  • Tap a button and it runs right away; the card flashes white when it worked and red when it failed (with the explanation). Buttons with confirmation ask for a second tap.
  • State buttons (mute, microphone) keep their light on while active.
  • The screen doesn't dim while the app is open. On Android, use the full screen button in the corner to hide the bars.
  • Changed something in the editor? The phone updates by itself within two seconds.

6DJ, modes and calls

🎵 DJ

The DJ page becomes a full-screen player with whatever is playing on the computer — Spotify, Music, YouTube in the browser, any player — with artwork, time, back, play/pause, skip and volume. YouTube videos show up with the video's thumbnail, in full (16:9). Tap the bar to jump to another point. On the other pages a mini player shows up in the corner: tap it to open the DJ. Any page can become a player in Page › Page type › Player.

🎯 Modes

One tap gets the computer ready for the moment: turns on Do Not Disturb, opens apps and sites, closes distractions, sets the volume, switches page and shows a big timer on the phone (pause, +5 min, end — it can be minimized). Another tap turns it off and undoes Do Not Disturb. Only one mode is on at a time. Focus, Work, Study, Home and Break come ready.

📞 Calls

The deck brings the call window to the front and presses the app's own shortcut. In automatic, it finds the open meeting by itself (Meet, Zoom, Teams, Webex or FaceTime); for Discord and Slack, choose the app on the button. With no call open, mute silences the computer's microphone.

Do Not Disturb on each system

ComputerHow it works
MacThrough the Shortcuts app (macOS 12 or newer). Create two shortcuts once, with the Set Focus action: Deck Focus On (Do Not Disturb › On) and Deck Focus Off (Do Not Disturb › Off). The names must be exactly these (the Portuguese “Deck Foco Ligar” and “Deck Foco Desligar” also work). Without the shortcuts, the mode does everything else and tells you on the phone what's missing.
WindowsWindows doesn't let programs turn on Do Not Disturb: the mode does the rest and reminds you on the phone to turn it on with Win+N.
LinuxOn GNOME, it turns on and off by itself (hides on-screen notifications).

8If something goes wrong

  • The app opens with a black screen (or "could not connect"): the phone isn't finding the computer at the saved address. Close the app (swipe up) and open it again with the deck on. If it persists, the address changed: open Connect phone — it warns when the computer's IP or name changed and shows the new QR code. To avoid repeating it, use the link by name (default on a Mac) or the USB cable.
  • Doesn't connect over Wi-Fi: guest and company networks isolate devices from each other. Use the USB cable or Bluetooth.
  • "Apple could not verify…" when opening Iniciar no Mac.command: that's the macOS warning for programs that didn't go through Apple. System Settings › Privacy & Security › Open Anyway (once only), or install with the Terminal line from the site, which has no such warning.
  • Key button does nothing on the Mac: Terminal is missing the Accessibility permission (section 2).
  • Open tabs don't show up on the Mac: Safari/Chrome is missing the Automation permission.
  • The DJ doesn't show what plays in the browser (Mac): some macOS versions hide what's playing from programs; Spotify and Music still show up. The play, skip and back buttons work the same.
  • The mode doesn't turn on Do Not Disturb on the Mac: check the two shortcuts in the Shortcuts app (section 6) — the names must be exactly “Deck Focus On” and “Deck Focus Off”.
  • "The port is already in use": the deck is already open in another window. Close the other one, or start with --porta 8788.
  • Lost the phone or want to disconnect everyone: start with --novo-link and scan again.

9Security

The editor and the QR code only open on the computer itself. Only whoever has the phone link (with the secret key inside) can press the buttons — and even then only the buttons you created; the phone never sends free-form commands. Nothing is sent outside: bookmarks, history and addresses stay on the computer. Use it on a trusted network: the local connection is not encrypted.
